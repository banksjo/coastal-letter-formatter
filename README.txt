This is a manual, one-click ONLYOFFICE plugin. It does not autostart.
It applies the current Coastal formatting rules to the active Word document.

Install depends on what Xestro's embedded ONLYOFFICE allows. If a private/manual
plugin installer is exposed, install the .plugin package. If Xestro blocks private
plugins, Xestro support will need to add the config.json to their ONLYOFFICE
pluginsData / tenant configuration.

IMPORTANT: Test on a copy first.
